# 玄机阁 · 八字排盘命理平台

一个**零依赖、纯本地运行**的八字命理平台：Python 标准库后端 + 原生 JS 前端，
自研天文历法引擎（节气、朔日、干支纪日），不依赖任何第三方包与外部接口。

![功能](https://img.shields.io/badge/功能-排盘·批八字·流年流月·今日运程-9e2b25)

## 快速开始

```bat
:: Windows：双击 start.bat，或
cd 算命
python -m server.main        # 默认 http://127.0.0.1:8766
python -m server.main 8800   # 自定义端口
```

浏览器打开 <http://127.0.0.1:8766> 即可。要求 Python ≥ 3.9（开发环境 3.12），无需安装任何依赖。

> 注意：8765 端口已被本机另一个项目（地图服务）占用，故默认端口为 **8766**。
> 首次使用可点「试试示例命例」一键体验八字功能，各新算法页面均带「示例」按钮。

## 功能总览

### 八字排盘
- 公历 / 农历（含闰月）录入，时辰可缺省；
- 四柱干支、十神（天干 + 三层藏干）、纳音、十二长生、旬空、胎元；
- 神煞：天乙贵人、文昌、驿马、桃花、华盖、禄神、羊刃、红鸾、天喜；
- 五行加权分布图、大运十步（顺逆排、起运数精确到月、交接日期）；
- 高级选项：**晚子时两流派**（换日派 / 早晚子时派）、**真太阳时**（内置 37 城市经度 + 均时差修正）；
- 出生时刻距节气交界不足 2 小时自动预警。

### 批八字
- 旺衰打分可解释：得令（旺相休囚死）+ 得地（通根加权）+ 得势（印比计数）→ 七档判定（含从格）；
- 扶抑 + 调候取喜用神；识别伤官见官、枭神夺食、财官双美、杀印相生、食神制杀、羊刃驾杀等八类格局；
- 生成十大板块结构化批文（总览/性格/格局/事业/财运/婚姻/六亲/健康/开运/大运），支持一键打印。

### 流年流月
- 以立春为界的流年 + 十二节气月排盘（跨年正确：丙午年丑月为辛丑）；
- 逐年评分与五档吉凶（上吉/吉/平顺/起伏/低伏）、主题词、刑冲合害要点、宜忌；
- 十年大运条一键切换，逐月卡片点击展开流月详解。

### 今日运程
- 当年 / 当月 / 今日三层评分卡；
- 整月日历热力图：逐日干支 + 评分着色，点击查看流日详解。

### 命例库
- SQLite 持久化（`data/charts.db`），载入 / 删除；前端本地记忆上次排盘。

### 紫微斗数
- 农历生日 + 时辰安星：命宫身宫、五行局（命宫纳音定局）、定紫微借数法；
- 十四主星（紫微系六星 + 天府系八星）、六吉（昌曲辅弼魁钺）、六煞（羊陀火铃空劫）、禄存天马；
- 生年四化标记、十二宫宫干（五虎遁）、大限（阳男阴女顺行）、空宫借对宫星；
- 传统 4×4 盘式布局，命宫主星特质简批。

### 梅花易数
- **时间起卦**（农历年支数+月+日起上卦、加时辰起下卦、总数取动爻）与**数字起卦**两种方式；
- 本卦 / 互卦 / 变卦三卦并排，六爻阴阳线可视化并标动爻；
- 体用生克定吉凶（用生体大吉、体克用小吉、比和吉、体生用耗、用克体凶），互变卦修正；
- 六十四卦白话断语。

### 八字合婚
- 双方完整八字对照：生肖年支、日支配偶宫（1.3 倍权重）、日主生克、年命纳音、五行互补五维评分；
- 每项给出刑冲合害明细与加减分依据，总分映射五档（天作之合 / 上等婚配 / 中吉之配 / 缘分平平 / 多磨之象）。

### 生肖流年
- 十二生肖与流年太岁关系：值 / 合 / 冲 / 刑 / 害 / 破 / 平；
- 支持任意年份切换，与已排命例联动标记本命生肖。

### 星座命盘（西方占星）
- 七曜真实天文定位：太阳月亮用 Meeus 算法，水星～土星用 JPL 近似开普勒轨道根数；
- 上升 / 中天（恒星时 + 黄赤交角公式，出生城市经纬度参与计算），整宫制宫位；
- 四元素能量分布、太阳 / 月亮 / 上升性格解读；
- **今日天象**：当日七曜行运与本命行星的合 / 六合 / 刑 / 拱 / 冲相位与评分；
- 星座配对：元素与模式亲和度速查。

### 塔罗牌
- 标准 78 张韦特体系（22 大阿卡纳逐张撰写正逆位牌义，56 小阿卡纳数字原型×牌组领域）；
- **每日一抽**：按日期 + 署名确定性抽取（同一天同名同牌，可换名字换视角）；
- **三牌阵**：过去 / 现在 / 未来，随机抽三张、逆位牌面旋转呈现，按大牌占比 / 逆位比例 / 主导牌组生成综合解读。

## API 摘要

```
GET  /api/meta                  服务信息 + 今日干支
POST /api/paipan                八字排盘
POST /api/analysis              批八字
POST /api/fortune/year          流年流月（{input, year}）
POST /api/fortune/today         当年/当月/今日 + 整月日历
POST /api/ziwei                 紫微斗数（农历 y/m/d/leap + hour 时辰 + gender）
POST /api/meihua                梅花起卦（mode=time: y/m/d/hour；mode=numbers: n1/n2）
POST /api/hehun                 八字合婚（{a: input, b: input}）
GET  /api/zodiac/:year          生肖流年（太岁关系）
POST /api/astro                 西方占星本命盘（公历 y/m/d/hour/minute + lon/lat，with_today=1 附今日天象）
POST /api/astro/pair            星座配对（{a, b}）
POST /api/tarot                 塔罗（mode=daily: name/date；mode=three: question）
GET/POST/DELETE /api/charts     命例库
GET  /api/jieqi/:year           二十四节气表
```

输入字段：`name, gender(male/female), calendar(solar/lunar), y, m, d, hour, minute,
leap, zi_mode(late_swap/early_late), true_solar, lon`。

## 精度与流派说明

- 节气时刻误差 ±15 分钟内（Meeus 低阶算法），朔日 ±12 分钟内（月亮级数 26 项）；
  出生时间距节界 2 小时内时页面会自动提示；
- 晚子时默认按「换日派」（23:00 后日柱进位次日），可在高级选项切换「早晚子时派」；
- 神煞收录常用九种；批断为**规则引擎生成**，仅供文化研究与娱乐参考，
  不构成任何现实决策依据。
